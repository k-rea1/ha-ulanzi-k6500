# Ulanzi K6500 BLE Light

Control the **Ulanzi K6500** monitor light via **BLE** from Home Assistant.

## HACS install

1. **HACS** → **Integrations** → **⋮** → **Custom repositories**
2. Add this repo, type **Integration**
3. Install **Ulanzi K6500 BLE Light** and **restart** Home Assistant

## Add the device (UI)

**Settings** → **Devices & services** → **Add integration** → **Ulanzi K6500 BLE Light**

Enter the lamp’s **Bluetooth MAC** and optional **name**. Bluetooth must be working in Home Assistant.
